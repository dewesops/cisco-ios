## Port-Security

> Работает **только** после явного указания `switchport mode access` (или `trunk`).

```ios
int fa0/1
 switchport mode access
 switchport port-security
 switchport port-security maximum 1                  ! Макс. кол-во MAC-адресов
 switchport port-security mac-address sticky         ! Авто-запоминание первого MAC
 ! Или вручную: switchport port-security mac-address XXXX.XXXX.XXXX
 switchport port-security violation shutdown         ! shutdown | restrict | protect
 switchport port-security aging time 225             ! Время жизни MAC (мин)
 exit
```

### Восстановление порта из `err-disabled`

```ios
int fa0/1
 shut
 no shut
 exit
```

## DHCP Snooping

```ios
ip dhcp snooping
ip dhcp snooping vlan 10,20
no ip dhcp snooping information option               ! Нужно в PT, если DHCP на роутере

! На аплинке или порту в сторону легитимного DHCP-сервера:
int g0/1
 ip dhcp snooping trust
 exit
```

## Dynamic ARP Inspection (DAI)

> Включать **строго после** настройки DHCP Snooping и получения IP-адресов всеми ПК.

```ios
ip arp inspection vlan 10,20

! На аплинк-портах:
int g0/1
 ip arp inspection trust
 exit
```
